SETUP ON FIRST LAUNCH

First-time setup

  1. Tap Select folder (or Auto search) and choose the folder that contains GTAIV.exe.
  2. Press PLAY GAME. The first launch prepares the game files and may take a moment.
  3. After that the game starts straight away with the touch controls loaded.

About

This is an unofficial launcher built on the open-source Winlator project (LGPL-2.1): Wine, Box64, DXVK, Turnip.
Game files are not included. You need to select your own legally obtained copy of GTA IV.
Grand Theft Auto IV, its name and artwork belong to Rockstar Games. This app is not affiliated with Rockstar.
